# Update Info: Tools, AI Agent, and Design (Minggu Ini)

## 🛠️ TOOLS TERKINI
- **Stacked Pull Requests (GitHub Preview)**  
  GitHub kini menyediakan fitur *stacked pull requests* secara publik (public preview). Fitur ini memudahkan developer memecah perubahan besar menjadi rangkaian PR kecil yang saling tumpuk, yang bisa di-review terpisah dan di-merge dengan sekali klik. (Sumber: [GitHub Blog](https://github.blog/changelog/2026-07-30-stacked-pull-requests-are-now-in-public-preview/))
- **Visual Studio Update - Copilot Agent and Skills**  
  Update terbaru Visual Studio (Juli 2026) membawa *Agent Preview* dalam Copilot Chat dan built-in skill untuk .NET serta Azure, memungkinkan agen AI melakukan pekerjaan pengembangan yang lebih terstruktur. (Sumber: [Visual Studio Magazine](https://visualstudiomagazine.com/articles/2026/07/30/visual-studio-july-update-brings-copilot-agent-and-built-in-skills.aspx))
- **OpenAI Codex Security CLI**  
  OpenAI telah merilis Codex Security CLI (secara open source) yang membantu tim secara otomatis memindai dan memvalidasi keamanan kode menggunakan integrasi CI dan SDK. (Sumber: [The Agent Times](https://theagenttimes.com/articles/openai-open-sources-codex-security-cli-under-apache-2-0-lice-64143af2))

## 🤖 AI AGENT and TECH
- **Gemini API Managed Agents: 3.6 Flash and Environment Hooks**  
  Google merilis peningkatan besar untuk *Managed Agents* di mana *Gemini 3.6 Flash* kini menjadi default. Penambahan fitur seperti "environment hooks" juga memungkinkan pengawasan panggilan tool secara real-time. (Sumber: [Google Blog](https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api-3-6-flash-hooks/))
- **Deep Agents v0.7 Rilis**  
  LangChain merilis Deep Agents v0.7. Rilis terbaru ini menghadirkan perbaikan performa (penghematan token hingga 65%) dengan menghilangkan *system prompt* default, mengurangi ukuran deskripsi tool, dan memperkenalkan fungsionalitas kustom yang lebih dalam. (Sumber: [LangChain Blog](https://www.langchain.com/blog/deep-agents-v0-7))
- **Perplexity Numbat: Framework Keamanan untuk AI Agents**  
  Perplexity AI membuka sumber Numbat, yaitu kerangka kerja keamanan tingkat lanjut (real-time hooks, 52 aturan) yang dibuat untuk memantau dan memblokir "kegagalan tidak disengaja" (accidental meltdowns) pada autonomous agents. (Sumber: [Metaverse Post](https://mpost.io/perplexity-ai-open-sources-numbat-to-block-ai-agent-accidental-meltdowns-in-real-time/))
- **Microsoft EvoLib**  
  Microsoft merilis EvoLib, yakni *test-time learning framework* untuk para agen LLM, memungkinkan LLM mengoptimalkan dan meningkatkan kemampuan tanpa memperbarui *weight* / parameter internal model secara drastis. (Sumber: [RuntimeWire](https://runtimewire.com/article/microsoft-evolib-llm-agents-learn-without-weight-updates))

## 🎨 DESIGN and UI/UX
- **Replit Design Diluncurkan**  
  Replit memperkenalkan Replit Design, AI-native design canvas yang memungkinkan pembuatan antarmuka (UI/UX) hanya melalui natural language prompt yang didukung berbagai model unggulan. Fitur mencakup akses eksklusif ke referensi Mobbin langsung di dalam lingkungan Replit. (Sumber: [Replit Blog](https://replit.com/blog/introducing-replit-design))
- **Tren "Barely-there UI", "Tactile Realism" and "Liquid Glass"**  
  Menjelang akhir tahun, para desainer kembali ke antarmuka transparan (*Barely-there UI*) yang meminimalisir batas elemen, dikombinasikan dengan kembalinya tren kedalaman grafis transparan ("Liquid Glass") dan *Tactile Realism* untuk menandakan gaya buatan tangan (human-made) ketimbang AI. (Sumber: [Bubble Web Design Trends 2026](https://bubble.io/blog/web-design-trends/))
- **Tencent Ardot Beta - AI Design Agent**  
  Tencent merilis Ardot Beta yang berfungsi asisten agen desainer. Ardot secara otomatis mengubah deskripsi spesifikasi ke antarmuka desain visual, bahkan langsung mengkonversikannya menjadi format kode front-end. (Sumber: [xix.ai](https://xix.ai/ainews/tencent-unveils-ardot-beta-ai-design-agent-generates-ui-from-natural-language-converts-to-code.html))
